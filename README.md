# Branching Dialogue Tool

A small, opinionated node-based dialogue editor for games. It's built for branching dialogues for games with global conditions and traits. It assumes a particular JSON parser in-engine, but onces this is set up, it's very easy to write dialogues via an import/export workflow. The primary goal is making branching dialogues simpler to visualize and to reason about (compared to, say, writing raw JSON).
